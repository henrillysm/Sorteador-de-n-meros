# Sorteador de Números

Projeto desenvolvido a partir de um desafio da Rocketseat. A aplicação permite sortear números dentro de um intervalo definido pelo usuário, com a opção de evitar números repetidos.

## Funcionalidades

- Escolher a quantidade de números a sortear.
- Definir os valores mínimo e máximo do intervalo.
- Ativar ou desativar a repetição de números.
- Sortear novamente e visualizar cada resultado.
- Exibir os números com animação.
- Validar os campos e mostrar mensagens para intervalos inválidos ou quantidades incompatíveis com o intervalo, quando a opção de não repetir estiver ativada.
- Resetar o sorteio e voltar ao formulário inicial.

## Personalização

Foi adicionado o botão **Resetar**, que limpa os resultados exibidos e permite iniciar um novo sorteio.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.

Também é possível executar o projeto com a extensão Live Server do VS Code.
